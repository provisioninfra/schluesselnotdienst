# SEO-Projekt provision-infra.de

Arbeitsordner für das SEO-Mandat der ProVision Infra GmbH (WordPress, Elementor, Yoast, Raidboxes).

- `daten/inventory_rest.csv`: URL-Inventar aus der WordPress-REST-API mit Yoast-Daten (Titel, Description, Canonical, Index-Status).
- `daten/google_suggest.json`: Suchvorschläge von Google für die Keyword-Seeds (echte Suchanfragen, ohne Volumina).
- `01-audit-phase1.md`: Auditbericht mit Befunden, Maßnahmen und Freigabeliste (folgt nach Abschluss der Messungen).
